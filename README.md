# Bible Quiz - Node.js + Express Starter

## Quick start

1. Install dependencies:
   npm install
2. Run in development mode:
   npm run dev
3. Open in browser:
   http://localhost:3000

## Structure

- app.js - backend entry point
- frontend/index.js - frontend starter entry file
- public/ - static assets (css/js/images)
- views/ - EJS templates
- src/routes/ - route files
- src/controllers/ - controller files
- src/models/ - model files
- src/middleware/ - custom middleware
